# `게임 2` 첫 채팅 시작문

업로드된 정본과 이미지를 먼저 대조해줘.

이번 채팅의 목적은 전체 맵 시안을 새로 그리는 것이 아니라, `LATEST_SCREEN.png`의 ACT 2 실제 플레이 화면이 우리가 정한 맵 철학에 맞는지 판정하는 것이다.

배경과 맵만 평가하되 캐릭터가 그 안에서 잘 읽히는지는 반드시 포함해줘. 다음을 각각 판단해줘.

- 강을 따라 성소로 올라가는 길로 읽히는가
- 카메라 pitch 60 / yaw 20 / orthographic size 22 후보가 지나치게 탑다운이거나 답답한가
- 길 폭이 다수전과 회피에 충분한가
- 지면·물·식생·석재 중 무엇이 캐릭터보다 튀는가
- 배치가 자연 지형인지, 예쁜 타일맵인지
- 기존 재사용 자산과 셰이더 수정만으로 해결할 것과 새 에셋이 꼭 필요한 것을 분리할 수 있는가

먼저 `통과 / 수정 / 아직 판단 불가`로 판정하고, 가장 비용 대비 효과가 큰 수정 3개까지만 제안해줘. 사용자 승인 전 새 이미지 생성이나 전체 맵 확장은 하지 마.
