# 다음 세션 인계 — 2026-09-25 사용자 중단 시점

## 최신 정정 — 개별 다리 수리 중단, `grove_scholar` 동작 리스킨으로 교체

사용자가 이 세션에서 작업을 재개한 뒤 기존 `hero_pose_v2`의 걷기·달리기와 관련 수리 시도를 전부 폐기/배제하고, 예전 초록 `grove_scholar` 동작에 승인 현재 디자인만 입히도록 지시했다. 따라서 아래의 ‘뒤대각선 F2/F3 수리’ 재개 순서는 폐기된 계획이며 다시 실행하지 않는다.

현재 구현은 `assets/hero_reskin_v1/` 네 시트와 `lab/hero_reskin_locomotion.gd`다. 기존 초록 보행/달리기 4×4 배열·방향·위상·root/발 기준점을 유지하고 `hero_turnaround_approved.png`의 크림색 털·큰 귀·아이보리/남색/금색 갑옷·청록 보석·검정 장갑/부츠·왕관 외형으로 리스킨했다. 새로 만든 이동 strip은 실패 폴더로 격리했고 런타임 참조가 없다.

`approved_hero_visual.gd`의 걷기·달리기는 신규 리스킨만 사용하고, `hero_pose_player.gd`는 공격만 로드한다. 알파 파편·키색 테두리·셀 샘플링 세로선을 제거한 후 GPU 8방향 4상 픽셀 검수와 통합 96 PASS/0 FAIL을 다시 통과했다. 직출력은 `raw_generated/`에 보존되어 클린업은 복구 가능하다.

상태는 `RESKIN_CANDIDATE_NOT_USER_ACCEPTED`다. 기본 boot에는 아직 승격하지 않았고, 이 최신 이동 미술과 남은 공격 미술의 사용자 수용은 별도다. 상세는 `docs/CHARACTER_GOAL_STATUS.md` 최신 절과 `experiments/terrace/assets/hero_reskin_v1/README.md`.

**캐릭터 미술은 미완성·검수 불합격이다. 최신 소스는 완성본이 아니라 중단 시점의 작업본이다.**

사용자가 좌상·우상 다리와 복장 오류를 재차 지적한 뒤 작업 중단과 인계를 요청했다. 이 문서의 판단이 과거 로그의 ‘교정했다/검수했다’ 표현보다 우선한다. 원본 로그는 정정 이력과 함께 보존했다.

## 사용자가 확정한 조건

- 최종 목표는 **8방향**. 4방향은 중간 단계일 뿐이다.
- 승인 외형은 [이 원화](docs/design_refs/hero_turnaround_approved.png) 하나다. 다른 생성 그림을 새 기준으로 삼지 않는다.
- 멈춤·걷기·달리기를 구분한다. 오징어처럼 다리를 휘는 메시 변형은 기각됐다.
- 공격은 무기 없는 맨손 마법 3연타: 가로 휘두르기 → 반대 되치기 → 크게 사선 내려치기.
- 공격하면서 이동할 때 미끄러지지 않아야 한다.
- 위·위대각선 달리기의 발과 다리 연결을 바로잡고, 꼬리 뿌리는 골반 중앙에 둔다. 끝부분은 걸음에 맞춰 살랑인다.
- 기본/걷기/달리기 복장을 일치시키고, 여우불은 힘 있게 불덩이를 발사하는 느낌을 낸다.
- 위 수정 범위를 마친 뒤 남은 일을 보고하고, **다음 작업은 사용자 허락 후 진행**한다.
- 최신 지시는 **중단 및 인계**다. 이 문서를 읽었다는 이유만으로 자동 재개하지 않는다.

## 이번에 잘못됐던 판단

1. 발끝만 오른쪽으로 돌린 그림을 보고 골반·무릎·발목 전체가 정상이라고 판단했다.
2. 두 컷이 거의 같은 자세거나 반주기에서 좌우 다리 연결이 바뀌었는데 교대 동작으로 채택했다.
3. 원화에 없는 장식을 없애면서 원래 복장 디테일까지 단순화했다.
4. 기능 검사와 작은 GPU 캡처 확인을 미술 품질 통과처럼 설명했다.

**이 판단들은 철회한다. 사용자가 발견한 오류가 맞으며, 기능 테스트 숫자로 해결됐다고 말하면 안 된다.**

특히 색으로 다리를 구분한 4컷 생성본에서 3번째 컷의 파란 왼다리/빨간 오른다리가 골반에 붙는 관계가 뒤바뀌어 보였다. 복장도 승인 원화와 달랐다. [기각 증거](docs/design_refs/character_rejected_20260925/README.md)에 보존했다. 참고 증거일 뿐 게임 자산이나 정답으로 사용하지 않는다.

- 검수 실패한 로컬 적용 상태를 인계 목적으로 그대로 보존했다. 임의로 옛 버전을 완성본으로 되돌리거나 기본 게임에 적용하지 않았다.

- **최신 가이드로 새 원화를 생성하기 전에 사용자가 중단했다.** 실행 중인 이미지 생성 요청은 없다.

## 다음 세션의 시작 순서 — 사용자 재개 지시 후

1. 이 문서 → 승인 원화 → 기각 증거 → 현재 활성 5/7방향 source와 전체 GPU 시트를 읽는다. 옛 ‘완료’ 표현을 믿고 넘어가지 않는다.
2. 좌상·우상 **한 주기**의 양쪽 고관절 연결, 무릎 굽힘, 발목/발끝 방향, 지지발 교대를 확인한다. 단순 화면상 좌우 위치와 해부학적 좌우를 혼동하지 않되, 연결 관계가 그림에서 읽혀야 한다.
3. 같은 후보를 승인 원화와 대조해 어깨판·등 장식·중앙 청록 패널·양옆 흰 코트·남색 바지·검정/금색 부츠를 확인한다. 오류를 감추려고 옷을 새 디자인으로 단순화하지 않는다.
4. 골반 중앙 꼬리 뿌리가 프레임마다 옆구리로 옮겨 붙지 않는지, 끝부분만 리듬에 맞춰 움직이는지 확인한다.
5. 구조/복장이 통과한 뒤에만 atlas와 runtime에 교체한다. 확대 4컷과 실제 크기 연속 재생 양쪽에서 보고, 실패하면 미채택으로 남긴다. 같은 실패 프롬프트로 전체 시트를 반복 생성하는 방식은 피한다.
6. 아직 남은 사용자 피드백(복장 전체 연결, 여우불/평타 체감 포함)을 마무리하고 보고한다. 그 다음 전 방향 최종 정리·기본 게임 승격 등은 별도 허락을 받는다.
