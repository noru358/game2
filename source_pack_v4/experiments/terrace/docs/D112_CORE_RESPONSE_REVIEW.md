# D112 — Packet 1 이동·전투 반응성 부분 구현

2026-09-24. 최종 목표는 본편 Steam 출시/초기 안정화이고, 현재는 **P1 핵심 경험 검증/P2 대표 데모 제작 · M1-A**다. 이번 작업은 [Packet 1](../../../docs/NEXT_IMPLEMENTATION_PACKETS.md)의 **미술 최종화에 의존하지 않는 입력 반응성**만 다뤘다. 캐릭터 원화, 환경 미술, 지형·지역 구성, Packet 2는 변경하지 않았다.

## 관찰과 변경

기존 자동검사는 이동·3연타·자동 공격의 기능 존재를 확인했지만 두 입력 경계는 직접 다루지 않았다.

- 달리기 최고속도 도달에 1.8초가 걸려 첫 이동과 재출발의 빠른 체감이 늦었다.
- 좌우 또는 상하를 함께 눌러 실제 방향이 0이어도 달리기 가속 시간이 쌓였다. 한쪽 키를 놓으면 제자리에서 미리 충전한 최고속도로 출발할 수 있었다.
- 직접 공격 회복은 일반타 0.36초/마무리 0.52초인데 탭 버퍼는 항상 0.18초였다. 회복 초반에 다음 타를 눌렀다가 손을 떼면 회복 전에 버퍼가 사라졌다. 길게 누르면 이어졌으므로 기능 존재 검사만으로는 이 손실을 찾기 어려웠다.

변경은 다음 세 가지다.

1. 이동 최고속도 도달 시간을 **1.8초 → 0.75초**로 줄였다. 시작속도 7.5, 최고속도 10.0, 회피 속도·시간·대기시간은 유지했다.
2. 달리기 가속은 누른 키의 개수가 아니라 **실제 합성 이동 방향이 있을 때만** 쌓인다. 손을 떼거나 반대 방향 입력이 상쇄되면 즉시 정지하고 가속도 초기화한다. 이동 중 방향 반전은 현재 속도를 유지한 채 다음 물리 프레임에 반영한다.
3. 직접 공격은 회복 중 누른 **한 번의 탭만** 남은 회복시간+0.12초 동안 예약한다. 반복 입력을 여러 타로 쌓지 않으며 회피는 기존처럼 예약·회복·연타 상태를 모두 취소한다. 히트스톱 중 입력도 만료시키지 않는다.

0.75초와 +0.12초는 이번 체감 후보값이며 사람 플레이 승인값이 아니다.

## 변경하지 않은 것

- 이동 시작속도/최고속도, 회피 거리·무적·대기시간
- 직접 공격 피해·사거리·각도·1/2/3타 회복시간·밀치기·경직·히트스톱
- 자동 공격 표적·피해·간격·분열/연쇄/응축 성장
- 적 수·AI·물리·경고·체력·강적 행동
- 캐릭터/적 원화, 보행·시전 프레임, VFX·음향 자산
- 지형·경로·카메라·환경 미술·UI·이야기·저장 schema

따라서 이 작업은 보행/타격/음향 미술 완성이나 Packet 1 전체 완료가 아니다.

## 자동·GPU 검증

새 `tests/core_response.gd`는 수정 전 4개 항목에서 실패했고 수정 후 6개 항목이 통과했다: 0.75초 내 최고속도, 한 프레임 정지, 상쇄 입력 무가속, 한 프레임 최고속도 반전, 첫 탭 시전, 회복 초반 탭의 정확히 한 타 예약.

기존 회귀는 `grounded_run`, `moving_strike`, `diagonal_strike`, `gait_cycle`, `strike_range`, `lab_combat`, `lab_growth`, `warning_damage`, `warning_cache_contract`, `keyboard_choices`, `save_queue_contract`가 실패 0이었다. `hand_origin`은 headless에서 `frame_post_draw`를 기다려 멈춘 실행을 이번 QA PID만 종료했고, 실제 GPU로 다시 실행해 실패 0을 확인했다.

GPU 모션 검사는 `gait_cycle`, `moving_strike`, `diagonal_strike`, `hand_origin` 모두 실패 0, 총 131장 캡처를 남겼다. 대표 화면에서 8방향 걷기/질주 단계, 접촉 뒤 보행 복귀, 대각선 회복, 3타 손 기준점을 픽셀로 확인했다. 이는 프레임/부착 계약 확인이며 자연스러운 모션이나 현재 작화 승인 근거가 아니다.

실제 AI·충돌·경고·자동/직접 공격·PID 전용 저장을 켠 GPU 전투:

| 조건 | 프레임 p95 | 최대 | 물리 콜백 p95 | 최대 |
|---|---:|---:|---:|---:|
| 혼합 2 | 18.176ms | 19.261ms | 3.146ms | 4.095ms |
| 혼합 8 | 18.235ms | 19.536ms | 4.420ms | 5.176ms |
| 혼합 24 | 19.042ms | 22.005ms | 7.406ms | 10.834ms |
| 사원 혼합 24 + 강적 | 19.093ms | 22.673ms | 7.631ms | 9.642ms |

사원 강적 경고는 72프레임, 전체 적 경고는 154프레임 관찰됐다. D107의 수초 정지는 재발하지 않았다. 같은 RTX 4060 Ti/Windows/OpenGL 조건의 짧은 검사이며 장시간·다른 PC 보장은 아니다.

최종 `0.10-core-response` 실행본에서 새 반응성 검사 실패 0, 전체 여정 28검사 실패 0, 버전·3지역·성장·고유 PID 저장·복원·결말 연결과 GPU 캡처 14장을 확인했다. 숨긴 QA 프로세스에서는 WASAPI 장치를 열 수 없어 dummy audio로 대체되었으므로 **실청음은 검증하지 못했다**.

첫 export는 PowerShell이 공백이 있는 preset 이름을 잘라 `Experience`로 전달해 산출물 없이 실패했다. `Experience Lab`을 단일 인자로 다시 전달한 export는 성공했다. 이 실패를 게임 결함으로 기록하지 않는다.

## 사람이 확인해야 할 것

ExperienceLab-0.10.exe (원본 작업공간의 별도 이력/산출물: `../builds/ExperienceLab-0.10.exe`; 이 팩 제외)에서 다음을 한 흐름으로 5~10분 확인한다.

1. 짧게 이동했다 멈추기와 좌우/대각 반전을 반복할 때 빠르면서 과하게 미끄럽지 않은가.
2. J를 누르고 뗀 뒤 회복 초반에 다음 J를 미리 눌러도 2타/3타가 의도대로 한 번씩 이어지는가.
3. 공격 도중 Space 회피가 연타 예약을 취소하고 실제 위기 대응으로 느껴지는가.
4. 자동 마법이 약한 무리를 정리하는 동안 직접타로 원거리/돌진/강적의 위험을 끊을 이유가 있는가.
5. 일반타와 마무리 밀치기가 공간을 되찾는 느낌을 주는가.
6. 손·마법·적 반응·소리가 한 접촉으로 들리고 보이는가. 반복음과 이펙트가 피곤하지 않은가.

자동검사만으로 위 항목을 승인하지 않는다. 치명적 체감 문제가 없다는 사용자 확인 전에는 Packet 1을 완료 처리하거나 Packet 2로 넘어가지 않는다. B′ G1 미술 준비 상태도 그대로 유지하며 대량 원화/환경 교체를 시작하지 않는다.

증거: `docs/validation/d112`. 사용자 실제 저장과 실행 중 게임은 열거나 종료하지 않았다.

Mac에서는 Windows `.exe` 대신 [0.10 macOS universal ZIP과 실행 안내](D113_MACOS_BUILD.md)를 사용한다. 같은 게임 데이터의 별도 패키지이며 D112 체감 승인 상태는 바뀌지 않는다.
