## 실행

작업공간 `PLAY_WATER_ENTRY_DIRECTION.cmd`.

WASD 이동, 1 제안안45/45, 2 이전55/30, 3 낮은40/45, P 대표 위치, G 구조, Tab 조감, R 시험 적 재배치, J 공격, Space 회피, Esc 종료. 일반 게임 boot와 운영 저장은 변경하지 않는다.

## 제작 기반

- 문서: `docs/maps/FOREST_REGION_DIRECTION.md`. 여섯 결정과 구역 간 수로/높이/출입 관계. 이번 장면은 1구역의 대표 진입부만 구현.
- `ruin_layouts` C 데이터: 양쪽 땅 사이의 낮은 수로, 다리, 열린 접근부, 계단, 상층 문과 다음 구역 접속 예정점.
- `water_entry_direction`: 실제 깊이를 가진 석문. 정면 사원 그림 사용 안 함. 앞/옆/위가 지면과 동일 투영. 문 안에서 지붕을 숨기고 되돌아오면 복원.
- 기존 캐릭터·적·전투를 재사용한다. 캐릭터 미술을 승인하거나 수정한 작업이 아니다.
- 공통 builder의 계단을 별도 재질 면으로 분리하고, 위치/충돌/높이의 같은 bevel 표면은 유지. C용 palette 옵션은 A/B 기본 재질 설정을 바꾸지 않음. 계단 표현은 개선됐지만 생성 목표의 실제 평평한 디딤면/수직 챌판과 아직 차이 있음.
