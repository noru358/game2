# 첫 숲 수로 · 세 막 그레이박스 검수

날짜: 2026-09-25  
정본 설계: [FIRST_FOREST_WATERWAY_MAP_SPEC](../../../../docs/maps/FIRST_FOREST_WATERWAY_MAP_SPEC.md)

## 범위

새 배경 에셋을 만들지 않고 하나의 연속 지형을 `물가 입구 → 굽이치는 강가 상승로 → 뿌리 성소` 세 막으로 구성했다. 상자·구체·색 띠·원통 뿌리는 공간 관계를 읽기 위한 디버그 표현이며 미술 기준이 아니다. 기존 `composition_proof`의 배치는 재사용하지 않았다.

실제 승인 캐릭터의 이동/달리기/회피/3연타와 기존 적·경고·자동 여우불을 연결했다. 기본 카메라 후보는 orthographic pitch60/yaw20/size22이며 게임 기본 진입점과 실제 저장은 바꾸지 않았다.

## 실행

작업공간 루트의 `PLAY_FOREST_PILGRIMAGE_GRAYBOX.cmd`.

- WASD: 이동
- Space: 회피
- J: 직접 3연타
- 1/2/3: 세 구간 시작점 이동
- Tab: 검수용 전체 조감
- F: 전투 정지/재개
- R: 전투 재배치
- B: 자동공격 켜기/끄기
- Esc: 종료

## 자동·GPU 검증

- headless: 21 PASS / 0 FAIL
- GPU OpenGL RTX 4060 Ti: 27 PASS / 0 FAIL
- 실제 입력으로 route의 모든 경유점을 지나 입구에서 성소까지 도달.
- 입구와 성소 높이차 4u 이상, 상층 도착 y>4.8.
- 승인 animated hero 활성, 실제 적 경고·직접 3연타·자동 여우불 동작.

## 실제 픽셀 판단

- 플레이 화면에는 지형판 끝이 노출되지 않고, 강이 오른쪽의 지속적인 방향 기준으로 남는다.
- 입구에서는 성소가 직접 보이지 않으며, 강가 말미에 뿌리와 기단 일부가 먼저 잡힌 뒤 세 번째 막에서 정면이 열린다.
- pitch60/size22에서 캐릭터 실루엣과 다수전 여백은 읽힌다. 배경 밀도가 없는 그레이박스 조건이므로 최종 가독성 합격은 아니다.
- 전체 조감에서 길이 실제로 굽지만 여전히 하나의 긴 상승 축으로 읽힌다. 이것은 샛길 없는 현재 요구와 일치한다.

## 남은 문제

- 세 구간의 색 띠, 구형 숲, 상자 석조, 원통 뿌리는 모두 교체 대상이다.
- 입구의 `신비롭고 성스러운` 정서와 동남아 성소의 문화적 형태는 아직 검증하지 않았다.
- 실제 식생 가림, 최종 석축 경계, 물 애니메이션, 재질 대비가 들어오면 캐릭터 가독성을 다시 확인해야 한다.
- 카메라 60/20/22는 첫 비교점이며 사용자 체감으로 조정한다.
- 이 결과는 MAP_SPEC과 플레이 공간 검증의 첫 단계이지 아트 슬라이스나 완성 맵이 아니다.
