# 8방향 보행 제작 — 대표 4방향 시험

2026-09-24. **최종 목표는 8방향이다.** 현재 4방향은 제작 방법과 모션 검증용이며 최종 범위 축소가 아니다. coverage.json에 8슬롯을 모두 기록했다. 대각선 1/3/5/7은 미제작이다.

## 실제 산출물

- candidate.png: 내장 imagegen으로 승인 시트에서 만든 4방향×4단계 보행 후보의 수정본. 최종 아트가 아니며 기존 캐릭터를 교체하지 않는다.
- frames.json: 16개 영역/발/root 잠정값. 프레임마다 높이를 정규화하면 몸통 떨림을 감추므로 고정 310px 기준으로 표시한다.
- review.png: Godot GPU에서 16컷을 각각 148px/74px로 렌더한 비교판.
- preview.html: 자동재생/정지/한컷/2~12fps/배경색 조절 웹 검수기. 브라우저 도구가 file URL을 정책 차단하여 웹 UI 동작은 미검증이다. 우회하지 않았다.
- tests/hero_walk_review.gd: 독립 Godot 검수기. `--script res://tests/hero_walk_review.gd -- --test`는 비교판 저장 후 종료. `-- --test --motion-test`는 2초간 6fps 반복 검사. 사용자 인자 없이 실행하면 연속 재생, Space 정지/재생, Right 한컷, Esc 종료. 실제 게임/저장과 독립이다.
- prompts.json: 사용한 내장 imagegen 프롬프트 전체. CLI/API 사용 없음.

## 확인 결과

영역/중복 방향-단계 16개 기본검사 통과. Godot4.7.2 GPU 비교판 저장 성공/오류출력 없음. 비교판의 16개 실제 픽셀을 승인시트와 대조했다. 반복검사는 2초 동안 12회 프레임 전환/캡처 성공/오류출력 없음. 이 숫자는 재생기 동작 확인이며 자연스러운 보행 통과가 아니다. 네 방향을 한 컷씩 비교했으나 사람의 실시간 연속재생 수용은 미완료다.

## 미통과

- 정면 4번째 꼬리가 반대쪽으로 튄다. 처음 후보의 뒤쪽 꼬리 전환은 수정본에서 완화됐지만 정면은 남았다.
- 오른쪽/왼쪽 1·3 접촉 자세가 비슷하여 어느 발이 교대하는지 불명확하다. 2·4의 통과 자세도 일관된 지지발과 무게중심으로 확정되지 않았다.
- 일부 머리·의상 크기와 세부 문양이 승인 시트에서 달라졌다. 발/root는 수동 잠정값이며 바닥 이동량과 접지 검증이 필요하다.
- 외곽 잔여 alpha는 지속된다. 정지 후보에 alpha만 정밀 수정 요청한 추가 시도도 실패하여 채택하지 않았다. 원본 시트는 변경하지 않았다.
