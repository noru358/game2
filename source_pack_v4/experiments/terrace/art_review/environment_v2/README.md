## 시각 비교 판단

개선: 단색바닥→포석/흙/풀 구분, 구형나무→참고계열잎그림/겹침, 반복바위테두리→일부숲가림, 사각벽→석조재질·높은옆면, 줄/점무늬물→표면이미지와잔잔한UV흐름. 밝은포석/청록물의과노출은첫GPU확인뒤낮췄다. 생성atlas는실제투명alpha로표시되며배경사각형없음을확인했다.

아직 부족: 참고보다 같은식생/기둥의반복이뚜렷함,수역의매끈한윤곽과일부저폴리바위,돌벽의연속성/단면구도,작은캐릭터의명암분리. 45도는현재검토기본값으로52도와C키비교가능하며최종시점승인이아니다. 전투VFX/실제적을넣은가독성과성능은미검증.

## 표시 계약 정정

기존맵전용preview_player는Player._ready의-52도rotation을남긴채cos보정을사용해크기/발위치가잘못됐다. 이번검토중발견하여hero_visual과같이수직카드rotation0+현재pitch의cos보정으로수정했다. 캐릭터원화/모션파일을변경한것이아니다. 과거map_preview_v1의물리접지PASS는이미지발anchor검사가아니었음을정정한다. 이번검사에실제projection좌표검사를추가했다.
