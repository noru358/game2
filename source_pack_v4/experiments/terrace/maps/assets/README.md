# 환경 화면02 생성 자산

2026-09-24. 내장 image_gen 사용, CLI/API 전환 없음. 사용자 배경 참고는 스타일/공간감만 적용하며 캐릭터·몹은 제외했다. 프로젝트에 원본 생성 PNG 바이트를 복사했고 Python 이미지 재작화·마스크 수정은 하지 않았다.

- [forest_props_v1.png](forest_props_v1.png): 1536×1024 RGBA. 식생3/기둥/돌무리/나무6부품. 생성물의 실제 alpha0 픽셀839,280, 최대alpha254. 실제 런타임은 atlas region/alpha scissor로 표시. 위/아래 부품이 균등512행을 넘는 곳이 있어 props.json은 실픽셀 경계에 맞춘 비균등영역이다. alpha통계/영역 분석은 Python 읽기전용이며 PNG를 고치지 않음.
- [surface_materials_v1.png](surface_materials_v1.png): 1254×1254, 지면/흙/포석/석조 4재질. 요청1024와 실제1254를 구별한다. 런타임 Image.get_region으로 627픽셀 사분면을 텍스처로 올림. 각면의 반복 경계는 완벽한 seamless라고 보증하지 않음.
- [water_surface_v1.png](water_surface_v1.png): 그림체 물표면. 단일 바닥 shader 내부에서만 샘플링, 별도 물plane 없음.
- [props.json](props.json): 원본 UV영역과 하단 접점. 작은 반투명 외곽을 잘라내는 threshold/가림은 엔진 표시 설정이며 원본 alpha 수정이 아니다.

생성 원본은 .codex/generated_images에도 남아 있고, 게임은 이 폴더의 복사본만 읽는다. 사용자가 확정한 최종 미술이 아니라 실제 장면 비교 후보이다. 원화 속 부품에 그려진 명암은 고정이므로 동적 광원과 완벽히 일치한다고 주장하지 않는다.

## 최종 생성 프롬프트

### forest_props_v1

Use case: stylized-concept. Asset type: ONE production game environment sprite atlas, 1536x1024 landscape, transparent RGBA background. Reference is STYLE ONLY. Ignore ALL characters, monsters, text and panel labels in reference. Draw only environment assets. Clean illustrated 2.5D forest ruin environment matching reference: crisp organic contour, readable leaf shapes, jade/deep teal shadow groups, olive/sunlit leaf tips, warm mossy limestone. Not watercolor, no blur, no low-poly look, no pixel art. Orthographic oblique game view approximately 45-52 degrees downward. Camera faces north: see tops and south-facing sides. Consistent light from upper left. Output a strict 3 columns by 2 rows atlas: each asset fully inside its own equally-sized cell, generous transparent margin (at least 40px), no contact between cells, NO labels/grid/text/background. Top-left cell: lush broad-leaf tropical understory bush with layered leaves and small yellow flowers, low broad silhouette. Top-middle: fern cluster with long elegant fronds, broad low silhouette. Top-right: dense taller broad-leaf shrub with deep shaded lower foliage, taller silhouette. Bottom-left: broken mossy limestone pillar standing on square stepped base, visible front and right side, vines small leaves. Bottom-middle: cluster of irregular mossy stones and low leaf plants, wide silhouette. Bottom-right: small tropical tree, crooked visible brown trunk with roots and large detailed layered leafy canopy, entire tree contained. Each cutout includes only asset and very subtle small contact shade immediately at its base; no ground island, no circular platform. Alpha background must be genuinely transparent, not a drawn checkerboard. This sheet will be split into six equal cells in a real playable Godot scene. No creatures, people, UI, scenery background, horizon, terrain patch.

### surface_materials_v1

Use case: stylized-concept. Asset type: ONE opaque square texture atlas for a playable 2.5D forest-ruins game, 1024x1024. Reference STYLE only: ignore characters, monsters, text. Exact 2 by 2 grid filling whole canvas, each 512x512 quadrant a material texture, zero gutters, no labels, no grid lines. All quadrants TRUE straight overhead orthographic SURFACE/albedo texture, no oblique perspective, no objects sticking up, no cast shadows (3D engine provides light). Upper-left: subtle olive and moss green woodland earth with sparse small clover and fine blades, broad quiet patches. Upper-right: warm beige compacted earth/gravel footpath, sparse small flat stones, no vegetation clumps. Lower-left: old irregular limestone paving, large pale cream polygonal stones separated by narrow earthy seams and a few fine moss patches, irregular shapes not square grid, readable clean illustrated edges. Lower-right: aged gray-beige masonry surface, broad horizontal irregular limestone blocks, subtle cracks and moss in seams, relatively quiet detail. Match reference's clean hand-drawn game illustration, flat clear color groups, restrained texture, NO watercolor or photographic noise. Textures should repeat within each quadrant without obvious center motif. This is a technical material atlas, not a scene or tilemap screenshot. No water, characters, creatures, text, frames, shadows or 3D diorama.

### water_surface_v1

Use case: stylized-concept. Asset type: single seamless water-surface albedo game texture, opaque square 1024x1024. Match ONLY the illustrated turquoise water in bottom panel of reference, ignore all characters, creatures, plants, stones, text, land. Fill whole canvas with calm clear blue-teal forest stream water seen directly from overhead, no perspective. Organic irregular interlocking broad translucent turquoise facets, sparse slender gently broken light cyan caustic lines and little ripple crests, subtle underlying darker teal depth. Clean 2.5D hand-illustrated game background with controlled crisp edges, no photographic noise, no watercolor paper, no pixel art. No circular polka dots, no regular lattice/grid, no wavy stripe pattern, no bubbles, no strong white highlights. Medium dark muted teal overall so it remains quiet behind game action. No shore, land, objects, creatures or labels. Tileable edges without prominent central motif.
