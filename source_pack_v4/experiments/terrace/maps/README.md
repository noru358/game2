# 맵 검토본 — 환경 화면02 / 물길 입구와 다음 맵 연결

2026-09-24. 실제 지형/출입구를 조작하는 첫 제작본. 최종 배경, 전투 데모, 완성 지역이 아니다.

## 실행

작업공간 루트 `PLAY_MAP_PREVIEW.cmd` 또는 Godot4.7.2에서:

```text
godot --path experiments/terrace res://maps/map_preview.tscn -- --test
```

WASD/방향키 이동, Space/Shift 기존 회피, F 발견/맵 이동, Tab 전체 조망, R 해당 맵 시작점, P 대표구간, V 이전재질 비교, C45/52도 비교, Esc 종료. 작업공간 launcher는 --env-focus로 대표구간에서 시작한다. 기본 game 진입점은 바꾸지 않았다.

물길 입구 남서에서 시작 → 왼쪽 둑길 → 북쪽의 넓은 둑 → 동쪽 석문 앞에서 F → 뿌리의 단상 입구 → 왼쪽 석문 앞에서 F로 귀환. 물길 중간 서쪽 석표는 선택 발견이며 출구를 막는 필수 수집물이 아니다.

## 이번 구현

- 서로 다른 두 맵의 실제 지형. 물길 입구 약54×47u, 다음 맵은36×34u 입구/오르막 검토 구간.
- 맵ID와 출입구ID 연결, 안전한 도착 위치/방향, 연속 재전이 방지, 왕복 뒤 발견 유지.
- 동일 삼각형 기반 바닥 mesh·충돌·높이 조회. 지면·물·둑길을 한 불투명 표면으로 표현. 수역은 진입 불가.
- 코드로 배치한 재사용 부품: 암석 경계, 수목, 석축, 석문. 환경의 공간감 시험이며 B′ 최종 미술 승인이 아님.
- 기존 Player를 상속해 이동/가속/회피 수치를 그대로 사용. 승인 정지8방향만 표시하며 캐릭터 담당의 새 모션 코드/원화를 수정하지 않음.
- 환경검토기본45도/size22, C키로기존52도비교, Tab조망. 새식생카드는화면거리기반투명화근사. 기본게임카메라와캐릭터제작파일은유지.
- 발견 상태의 PID별 임시 파일 왕복 검증. 종료 시 자기 임시 파일을 제거. 사용자 저장은 읽지 않으며 다음 실행까지 성과를 보존하는 제품 저장은 **아직 없음**.

## 구조와 공유 계약

- `map_preview.gd`: 두 맵 연결 데이터·실험 컨트롤러·발견 상태·UI.
- `map_surface.gd`: 맵별 지형과 삼각형 높이/법선. `ground.gdshader`: 동일 지형 표면의 물·길·지면 재질.
- `environment_kit.gd`: 재사용 공간 부품.
- `preview_player.gd`: 기존 Player 물리를 유지하는 표현 어댑터. 접촉 그림자는 현재 MapSurface를 참조. 옛 Landscape 기반 발자국은 이 장면에서 비활성.

현행 게임의 Landscape/AI/경고/저장 계약을 바꾸지 않았다. 맵별 surface를 공유하는 경계를 검토한 단계이며, 기존 AI/경고·발자국·미니맵·저장도 이 경계를 사용하게 연결하기 전에는 일반 게임에 교체 적용하지 않는다. 테스트 장면에만 별도 높이를 놓고 통합 완료라고 하지 않는다.

## 검증과 미완료

`tests/map_preview_review.gd`: 실제 물리 입력으로 주경로와 선택 발견·양방향 맵 이동, 초기/도착 접지, 기존 회피/정지, 수역 진입 방지, 임시 snapshot 복원/정리. GPU7장과 결과는 `art_review/map_preview_v1/`.

다음 단계: 사용자 동선/구도 검토 → 한 화면의 환경 표현 개선 → 기존 전투·AI/경고·미니맵을 같은 map surface에 연결 → 별도 테스트 프로필 종료/재실행 복귀 검증. 얼굴 사원은 아직 만들지 않음. 본편 규모·실제8~12분·전투 재미·소리·연속모션·전지역 미술 완성은 이번 검증 범위 밖.

## 중복·상충 자료 처리

- 기존 START_PARALLEL_WORK의 모든 맵 공통 갈림/재합류 지시를 교체했다.
- NEXT_IMPLEMENTATION_PACKETS의 강제 고저분기/갈림 통과조건을 실제 채택 경로 기준으로 수정했다. Packet1 체감 미완료와 맵 격리 제작 병행을 구분한다.
- Downloads ROOTS_TERRACE_BLOCKOUT_V01 및 이전 캡처는 과거 분석자료로 제외한다. 새 맵 템플릿/현행 실행 대상으로 사용하지 않는다.
- 옛 lab/journey/routes/Landscape는 현재 게임과 회귀검사 의존성이 있어 삭제하지 않는다. 과거 게임 상태와 새 맵 진행상태는 분리한다.
- 이전에 자동심사 차단된42파일 삭제는 재시도하거나 우회하지 않았다. 이번 정리는 활성 지시 교체와 참조 제외이며 원본 게임 삭제가 아니다.

## 환경03 — 2층 제단
뿌리의 단상을 아래마당→중앙계단→상부 제단의 야외 2층 필드로 교체했다. 실제 높이차4.2u,18단, 동일 지형·충돌로 걸어서 왕복한다. 위아래가 겹치는 실내 다층 구조는 아니다. 별도 맵을 추가하지 않고 기존 물길 출입구 연결을 유지한다. `altar_layout.gd`가 층·계단 높이와 경로의 기준이다.
실행: 작업공간 PLAY_MAP_PREVIEW.cmd. 2 제단 / P 물가 / Tab 조망 / WASD 이동 / F 조사·출입구. 최종 GPU47검사 통과, 증거 art_review/altar_v3. 미술 반복/외곽/제단 디테일과 전투통합은 후속 작업이다.

## 구도 시안 — composition proof

이전 맵의 굽은 띠·등고선형 석벽을 다듬는 대신, [맵 디자인 철학](../../../docs/MAP_DESIGN_PHILOSOPHY.md)을 별도 장면으로 검증한다. `composition_proof.tscn`은 전면 진입섬과 다리, 중앙 전투 지형, 실제 계단과 후면 고지 사원을 큰 landform으로 먼저 구성했다. 첨부 시안의 배치를 복제하거나 최종 미술을 구현한 장면은 아니다.

실행은 작업공간 `PLAY_COMPOSITION_PROOF.cmd`. `1/2/3` yaw15/20/25, `Tab` 전체/플레이, `F` 전투 정지, `R` 재시작, `T` 탐험. 전용검수 headless25/GPU31 PASS와 화면은 [구도 시안 검토 기록](../art_review/composition_proof_v1/README.md)에 있다. 기존 `map_preview`와 기본 게임 진입점은 교체하지 않았다.

## 첫 숲 수로 — 세 막 그레이박스

사용자가 확정한 `물가 입구 → 굽이치는 강가의 상승로 → 뿌리 성소`를 하나의 연속 지형으로 만든 새 검증 장면은 `forest_pilgrimage_graybox.tscn`이다. 기존 `composition_proof`의 배치나 임시 미술을 답으로 사용하지 않고, 실제 승인 캐릭터·적·경고·자동/직접 전투와 pitch60/yaw20/size22 후보를 연결했다.

실행은 작업공간 `PLAY_FOREST_PILGRIMAGE_GRAYBOX.cmd`. `1/2/3` 구간 이동, Tab 조감, F 정지, R 전투 재배치, B 자동공격. headless21/GPU27 PASS와 실제 화면·미완료 범위는 [그레이박스 검수 기록](../art_review/forest_pilgrimage_graybox/README.md)에 있다. 상자·구체·색 띠·원통 뿌리는 구조 검사용이며 최종 미술이 아니다.
