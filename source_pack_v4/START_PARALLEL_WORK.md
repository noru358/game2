# 병행 작업 안내 · 2026-09-24 현행

현재 상태는 [GAME_PROJECT_SOURCE](docs/GAME_PROJECT_SOURCE.md), 맵 제작 기준은 [MAP_DESIGN_AND_PRODUCTION](docs/MAP_DESIGN_AND_PRODUCTION.md)에서 확인한다. ZIP은 시점별 스냅샷이며 로컬/온라인은 자동동기화되지 않는다.

## 담당 경계
- 캐릭터 작업: 승인 원화, 최종8방향, 이동·시전 모션, 발 접촉·손/VFX. 맵 작업에서 이 파일을 다시 만들지 않는다.
- 맵 작업: 수제 맵 연결, 실제 지형과 환경 부품, 출입구/발견 상태. 캐릭터와 카메라52도·size22, 실제크기·속도·접지를 공유한다.
- 사람 검토: 조작·전투 체감과 첫 플레이/중단복귀를 실제 관찰한다. 테스트 통과를 재미 승인으로 대신하지 않는다.

## 맵 작업의 현재 범위
사용자가 설계안을 받아들이고 기존과 중복·충돌하는 것은 제거하거나 제외한 뒤 제작을 요청했다. 첫 제작은 물길 입구 전체 지형 + 뿌리의 단상 입구 구간 + 실제 출입구 왕복이다. 실행과 한계는 [맵 제작본](experiments/terrace/maps/README.md)을 따른다.

모든 맵에 ‘입구→갈림→전투→발견→재합류’를 의무화했던 이전 작업A 지시는 제거했다. 높은/낮은 길과 지름길은 공간적 이유가 있을 때만 쓴다. Downloads ROOTS_TERRACE_BLOCKOUT_V01은 이전 검토 자료이며 현행 제작 템플릿이 아니다.

## 다른 작업에 넘길 때
MAP_DESIGN_AND_PRODUCTION과 maps/README를 첨부하고 담당 파일을 명시한다. 현재 결과를 읽지 않고 같은 맵을 다시 생성하거나 캐릭터 담당 파일을 고치지 않는다. 반환물에는 실제 변경, 정상카메라 화면, 실행 검증, 미완료를 구분한다. 새 온라인 작업 생성/메시지 전송은 이 안내 작성에 포함되지 않는다.
