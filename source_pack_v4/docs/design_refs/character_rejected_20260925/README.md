# 기각 증거 — 게임 자산/승인 원화가 아님

- [몸·발 방향 오류](REJECTED_twisted_body_and_boot.png): 사용자 최초 지적. 머리/하체 방향 불일치와 잘못된 지지발, 두 자세 반복.
- [색 구분 다리 오류](REJECTED_colored_leg_identity.png): 파랑=왼다리, 빨강=오른다리로 제시했으나 3번째 컷 연결이 뒤바뀌어 보임. 사용자 기각. 색은 구조 구분용이지 복장 아님.
- [후속 복장·동작 기각 후보](REJECTED_costume_and_gait.png): 위 시트의 색을 남색 바지로 바꾼 후보. 다리 구조를 해결했다고 볼 수 없고 원화 복장/꼬리도 불일치. 미등록.

다음 세션은 이 그림들을 수정 완료본 또는 새 디자인 기준으로 사용하지 않는다. 유일한 외형 기준은 [승인 원화](../hero_turnaround_approved.png)다. 현황은 [인계 문서](../../../HANDOFF_START_HERE.md)를 따른다.
