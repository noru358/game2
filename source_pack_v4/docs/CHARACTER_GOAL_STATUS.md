## 2026-09-25 최신 대체 방침 — 기존 초록 캐릭터 동작 리스킨

- 동작 기준: `assets/hero/grove_scholar_walk_eight_v2`, `walk_pass_v2`, `run_eight_v1`, `run_pass_v1`의 4×4 배열·8방향·4상·기존 발/root 기준점.
- 외형 기준: `docs/design_refs/hero_turnaround_approved.png` 하나.
- 현행 자산: `assets/hero_reskin_v1/` 네 시트. 직출력은 `raw_generated/`에 보존, 현행본은 알파 파편/키 테두리만 결정론적으로 정리.
- 런타임: `approved_hero_visual.gd`의 이동은 `hero_reskin_locomotion.gd`만 사용. `hero_pose_player.gd`는 `state == "attack"`만 로드하며 이전 이동64프레임은 코드에서 배제.
- 실패 시안: `hero_locomotion_rebuild_v1` 두 strip과 `hero_repair_v3` 수리 후보는 런타임/신규 기준에서 배제. 다시 살리지 않는다.
- 검증: GPU 8방향 걷기4상+달리기4상 실제 픽셀 검수, 알파 셀 64개 분리 파편0, 이동/공격/회피/실제 AI 통합 96 PASS/0 FAIL. 최종 JSON은 `art_review/hero_reskin_v1/integration_qa.json`.
- 경계: 새 이동은 검수 장면에 통합됐지만 사용자 미술 승인 전이고 기본 boot로 승격하지 않았다. 공격72프레임은 현행 후보를 유지하므로 전체 캐릭터 미술 완성 선언은 아니다.

## 2026-09-25 새 세션 재개 — 최신 우선

후보08은 오른다리가 옆으로 과도하게 벌어져 사용자 기각. 오른다리를 안쪽으로 모은 후보09 한컷 검토 중이며 미등록/미승인. 후보08/09를 승인된 보행 기준으로 사용하지 않는다.

**최신 사용자 정정:** F2/F3는 상체도 잘못됐으므로 상체고정+하체합성 질문을 철회했다. 사용자 승인 순서는 승인원화/F0F1 대조→잘못된 F2F3를 구조참고에서 제외→첫 한컷 확인→나머지 제작→해당컷 교체/연속검수. 현재 `hero_repair_v3/walk_F2_candidate_08.png`와 `walk_F2_compare_08.png` 첫 걷기F2 검토 대기. 후보는 미등록, 기존 합성방식 선택 대기는 무효다.

사용자가 캐릭터 완성 작업 재개를 지시했다. 이전 중단 지시는 이 재개 요청으로 해제됐다. 미술불합격 상태는 유지한다. 짧은 다리/작은 보폭 허용, 단일 후보02의 다리 연결 방향만 수용했다. 실제 좌상/우상 상하체방향 불일치와 안짱다리 재지적으로 활성4시트8컷의 부분수정으로 전환한다. 후보5개 모두 미등록이며 기존런타임은 그대로다. 실제등록16컷 GPU와 사용/미사용 자산구분은 [활성자산감사](../experiments/terrace/art_review/hero_repair_v3/ACTIVE_ASSET_AUDIT.md). 원본상체 픽셀 고정+하체코드합성 방식을 사용자에게 질문 중. 최종완성/미술승인 아님.

**미술 검수 불합격. 좌상·우상 다리와 복장은 아직 해결되지 않았다.**

현행 상세 기준은 [다음 세션 인계](../HANDOFF_START_HERE.md)다. 사용자 재개 지시 전 추가 제작을 하지 않는다. 이전 수정 완료 표현은 아래 판단으로 정정한다.

## 구현되어 있는 것
- 승인 정지8방향, 이동64/공격72 후보 등록과 실제 전투 검수 장면 연결. 최종 목표는8방향.
- 멈춤/걷기/달리기, 맨손마법 가로→되치기→사선내려치기 3연타.
- 전신 공격 준비~마무리 접지 고정, 종료 후 걷기 재개, 회피 취소.
- 여우불 실제 비행/도착1회피해, 새 발사음과 효과.
- 직접공격 기본1.12배/성장1.20·1.28배, hitstop+0.012초.

## 완료하지 못한 것
- **좌상·우상 골반-무릎-발목 연결 및 좌우 다리 정체성/지지 교대.** 사용자가 반복 기각했다. 현재 활성 후보도 미승인이다.
- 위/위대각선 발 모양, 꼬리 중앙 부착과 리듬을 최종 확인하지 못했다.
- 승인 원화와 기본/걷기/달리기 복장의 일치. 추가 장식 제거 과정의 과도한 단순화도 다시 확인해야 한다.
- 전 방향 자연스러운 연속 동작 및 직접공격 손/몸 궤적 최종 미술 수용.
- 여우불/평타의 사용자 체감 및 발사음 실청음 수용.
- 기본 게임 진입점 적용. 기본 boot는 여전히 이전 캐릭터다.
