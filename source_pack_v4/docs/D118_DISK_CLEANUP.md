## 보존 및 검증

- 게임 소스, 디자인 원본, 검수 이미지 원본, 보관된 이전/현행 배포본, 실제 저장, 설치된 Godot/Windows/macOS export template 보존.
- 임시 엔진55개는 보존 엔진과 SHA256 동일 확인 후 삭제. 남은 QA 파일은 정확한 Temp 하위 경로/알려진 파일명/비실행 상태 확인 후 개별 정리.
- 원본 문서 이미지1,498개와 기존 디자인 PNG15개는 정리 후 SHA256 일치. 이후 누락 레퍼런스4개를 원본으로 회수해 디자인 목록은19개가 됐다.
- 설치용 압축 삭제 전 설치된 엔진/플랫폼 템플릿의 크기와 ZIP CRC 일치 확인.
- 실행 중인 ExperienceLab-0.8 PID35900 유지. 게임 실행/GPU/사람 체감 검사는 이번에 수행하지 않음.
- 광범위한 재귀 폴더 삭제는 자동 승인 검토에서 차단됐다(상세 사유 없음). 폴더 단위 삭제 대신 내용·원본·경로를 확인한 파일 단위 정리로 완료했다. 브라우저 프로필/세션/문서/다운로드 전체 삭제는 하지 않았다.

## 재발 방지

AGENTS.md에 QA 임시 복사본 수명/정리, 결과 증거 보존, 시작/종료 용량 확인을 추가했다. docs/.gdignore를 양쪽 Godot 프로젝트에 유지하여 문서 이미지가 런타임 자산으로 재변환되지 않게 한다. 이 규칙은 이후 작업 시 적용되며 자동 상주 청소 프로그램을 설치한 것은 아니다.

현재 게임 단계는 P1/P2 M1-A 그대로다. 저장공간 정리를 게임 완성 진척으로 계산하지 않는다. 공간 때문에 중단됐던 현행 소스팩 생성/검증을 재개한다.
