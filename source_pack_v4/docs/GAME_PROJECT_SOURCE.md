## 핵심 경험


- 귀여운 비인간 문관이지만 전투력은 매우 높은 술사. 절제되고 묵직한 손 마법.
- 넓고 읽기 쉬운 사선 시점, 자유로운 8방향 이동, 빠른 정지·반전과 구분되는 회피.
- 자동 마법이 다수 사냥의 주력. 직접 3연타·밀치기·회피로 위험 순간에 개입.
- 장소는 배경색·소품보다 지형·높낮이·전망·갈림길과 전투 방식으로 기억되어야 한다.
- 런 초기화 없이 성장·발견·열린 길이 남는다. 몇 분만 플레이하고 중단해도 성과가 있어야 한다.
- 여러 동양풍 지역을 여행한다. 첫 지역은 동남아 열대/몬순 숲과 오래된 수로·석조 유적 방향. 모든 후보 문화권을 출시 지역으로 확정하지 않는다.
- 미니맵은 전체 지형 + 발견물만 표시하는 방향이 확정됐다.

자동=약한 무리 정리, 직접=위험 차단·자리 회복·마무리라는 역할 구분은 실제 재미로 계속 검증한다. 높은/낮은 길이 전투 선택을 바꾸는지, 한 무리·한 발견이 짧은 세션 만족을 만드는지도 아직 검증할 가설이다.
