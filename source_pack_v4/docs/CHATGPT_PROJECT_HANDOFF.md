# ChatGPT `게임 2` 프로젝트와 로컬 구현 작업 연결하기

상태: 2026-09-25 기준 운영 안내  
공식 기능 안내: <https://learn.chatgpt.com/docs/projects>

## 먼저 결론

사용자가 만든 `게임 2`는 **일반 ChatGPT 프로젝트**다. 이 형식은 업로드한 파일·프로젝트 지침·연결 소스를 여러 채팅에서 공유하지만, 로컬 폴더에 직접 접근하지 않는다. 따라서 맵 철학 결정, 화면 비평, 문서 수정안, 제한된 코드 패치 초안에는 적합하지만 현재 Godot 파일을 직접 고치고 실행하는 Codex 로컬 프로젝트와는 역할이 다르다.

실제 파일 수정·Godot 실행·입력 경로·GPU 픽셀 검증은 이미 같은 앱에 등록된 로컬 프로젝트 `게임 v2`에서 계속한다. `게임 2`에는 매번 전체 ZIP을 올리지 않고, 현행 판단에 필요한 최소 정본과 최신 화면만 올린다.

## A→Z 설정

1. `게임 2` 프로젝트 생성은 완료됐다.
2. `deliveries/chatgpt_game2_setup`의 파일을 프로젝트 Sources에 개별 업로드한다. V8 ZIP 전체는 올리지 않는다.
3. 프로젝트 Instructions에는 같은 폴더의 `PROJECT_INSTRUCTIONS.txt` 내용을 붙인다.
4. 새 채팅을 `맵 설계·화면 검토`로 만들고 `START_PROMPT.md` 내용을 첫 메시지로 보낸다.
5. 이후 최신 화면이 생길 때는 이전 화면을 기준으로 계속 고치지 말고, `LATEST_SCREEN.png`만 교체해 비교한다.
6. 실제 구현이 필요해지면 ChatGPT가 만든 결정/패치 초안을 현재 로컬 프로젝트 `게임 v2`의 Codex 작업으로 넘긴다.
7. 가능하면 project-only memory를 사용해 다른 게임이나 과거 프로젝트 기준이 섞이는 것을 줄인다.

프로젝트 Instructions 원문은 별도 파일을 정본으로 두며 핵심 내용은 아래와 같다.

```text
이 프로젝트는 Godot 게임 v2의 맵 설계·화면 검토 프로젝트다.
업로드된 START_HERE.md, FIRST_FOREST_WATERWAY_MAP_SPEC.md, MAP_DESIGN_AND_PRODUCTION.md를 우선한다.
North Star v2의 정확한 배치를 복제하지 않는다. 전체 시안을 더 예쁘게 만드는 반복도 하지 않는다.
현재 세 막은 물가 입구 → 굽이치는 강가의 상승로 → 뿌리 성소이며 한 연속 맵이다. 형식적인 선택 구간을 추가하지 않는다.
기존 composition_proof와 map_preview는 기술 참고일 뿐 시각 목표가 아니다.
ChatGPT 프로젝트는 로컬 파일을 직접 고쳤다고 주장하지 않는다. 구현 제안과 실제 구현·실행 결과를 구분한다.
화면 평가는 캐릭터 가독성, 전투 폭, 강의 방향성, 높이 읽힘, 반복 자산 티, 한 화면 정보 밀도를 분리한다.
새 에셋 생성은 기존 자산으로 답할 수 없는 명확한 결손이 있을 때만 제안한다.
```

8. 프로젝트 안에서 목적별 채팅을 나눈다.
   - `맵 설계`: MAP_SPEC과 동선·카메라 판단
   - `맵 구현`: Godot 장면·지형·충돌 코드
   - `맵 화면 QA`: 캡처 비교와 수정 목록
9. 첫 `맵 설계·화면 검토` 채팅에 `START_PROMPT.md`를 보낸다.

```text
업로드된 정본과 최신 화면을 먼저 비교하라. 이번 채팅은 전체 맵을 다시 그리는 곳이 아니라 ACT 2 대표 플레이 화면이 맵 문법과 캐릭터 가독성에 맞는지 판단하는 곳이다. 먼저 화면의 통과점·실패점·가장 싼 수정 순서를 제안하고 사용자 승인 전 새 이미지나 대규모 에셋 세트를 만들지 마라.
```

10. 매 작업 응답에서 `판단`, `제안`, `Codex에 넘길 구현 항목`, `아직 확인하지 못한 것`을 분리해서 받는다.
11. 다음 중 하나가 생기면 같은 오류를 반복시키지 말고 Codex로 돌아온다.
    - 실제 로컬 파일 수정이 필요함
    - Godot 실행·입력·GPU 캡처 검증이 필요함
    - GDScript parse 오류를 실제 실행으로 확인하지 못함
    - GPU 캡처 없이 화면 품질을 완료라고 보고함
    - 충돌·높이·경고가 서로 다른 표면을 참조함
    - 승인 캐릭터 대신 옛 임시 캐릭터나 V8 이전 파일을 복원함

## 권장 역할 분담

- ChatGPT `게임 2`: 공간 의도, MAP_SPEC, 최신 화면 비평, 선택지 정리, 제한된 패치 초안.
- Codex 로컬 `게임 v2`: 실제 파일 구현, Godot 반복 실행, 입력 기반 경로 검사, GPU 픽셀 검수, 회귀 오류 수정.

ChatGPT에서 품질이 충분하면 그대로 이어가고, 위 인계 조건이 생길 때만 Codex가 같은 폴더에서 계속한다. 복사 프로젝트를 두 개 운영하지 않는다.
