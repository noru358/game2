## Packet 1 — 이동 + 전투 핵심 체감

### 목표

빠르고 정확한 이동 위에서 자동 마법이 무리를 시원하게 정리하고, 직접 3연타·밀치기·회피가 위험을 끊고 자리를 되찾는다는 핵심을 사람 플레이로 승인받는다. 성능 통과와 손맛 통과를 분리한다.

### 수정할 시스템/파일 후보

- `experiments/terrace/game/player.gd`: 가속·정지·회피·시전 전후 이동, 발 접촉과 자세 전환.
- `experiments/terrace/game/combat.gd`, `combat_effect.gd`, `hero_visual.gd`: 1·2·3타 리듬, 손/효과/판정, 밀치기와 회수.
- `experiments/terrace/game/world.gd`, `lab/spell_growth.gd`: 자동 표적·발사 간격·자동/직접 상호 강화.
- `experiments/terrace/game/enemy.gd`, `enemy_visual.gd`, `ridge_caster.gd`, `reservoir_keeper.gd`: 예고·피격·경직·돌진과 강적 반응.
- `experiments/terrace/game/sound_bank.gd`, `assets/audio/*`: 자동/시전/접촉/강타/위험의 음향 위계.
- 관련 검사: `moving_strike`, `diagonal_strike`, `gait_cycle`, `hand_origin`, `strike_range`, `warning_damage`, `live_combat_performance`, `warning_cache_contract`, `save_queue_contract`.

### 하지 않을 것

- 새 지역, 새 성장 경제, 새 장비, 새 이야기 분기 추가.
- 적 AI나 수를 꺼서 성능을 좋아 보이게 만들기.
- 전신 카드 회전·확대나 과한 전역 히트스톱만으로 타격감을 대신하기.
- 8방향 프레임 존재나 테스트 통과를 자연스러운 애니메이션 승인으로 기록하기.

### 자동검사 완료조건

- 평지·경사·좁은 길에서 대각선 이동/정지/반전/회피/이동 공격의 위치·방향 계약 통과.
- 8방향×성장 단계×3타의 손 위치, 판정 거리·각도, 밀치기·경직, 자동 표적 가시성 계약 통과.
- 근접·돌진·원거리·강적 경고가 실제 AI/물리/피해/음향/저장을 켠 상태에서 동작.
- 2/8/24마리와 경사/강적 조건에서 D107 성능 기준의 심각한 정지 재발 없음. 단발 지연과 측정 조건을 함께 기록.
- 키보드 강화 선택과 저장 종료/복귀 회귀 통과, stderr 비어 있음.
- 연속 캡처에서 발 접촉, 1·2·3타 접촉/회수, 자동/직접 동시 화면을 실제 픽셀로 비교.

### 반드시 사람이 플레이해서 확인할 항목

- 손을 떼면 정확히 멈추고 방향 전환이 즉각적인가.
- 회피가 빠른 이동의 반복이 아니라 위기 대응으로 느껴지는가.
- 자동 마법만으로 약한 무리를 정리할 때 시원하지만 지루하지 않은가.
- 직접 3연타가 타별로 구분되고 위험을 끊을 이유가 있는가.
- 밀치기가 공간을 되찾는 느낌을 주는가.
- 손·마법·적 반응·소리가 같은 접촉으로 느껴지는가.
- 5~10분 연속 전투에서 반복음과 이펙트가 피곤하거나 시야를 가리지 않는가.

### 다음 묶음으로 넘어가는 조건

사용자가 실제 0.10 후보 빌드를 조작해 이동, 자동 마법, 직접 개입 중 치명적인 체감 문제를 더 이상 보고하지 않거나, 남은 문제가 공간 배치 안에서 검증 가능한 수준으로 구체화되어야 한다. 자동검사만으로 Packet 2에 넘어가지 않는다.

## Packet 2 — 첫 숲의 탐험·지형·사냥 결합

### 목표

물길 입구, 뿌리의 단상, 얼굴 사원을 소품 이름이 아니라 지형·시야·이동·전투 방식으로 구별한다. 각 맵의 고유한 공간 행동과 실제 출입구 연결을 먼저 만든다. 갈림·재합류·고저 선택은 필요할 때만 도입하며 모든 맵의 의무가 아니다. 새 제작 기준은 MAP_DESIGN_AND_PRODUCTION.md를 따른다.

### 수정할 시스템/파일 후보

- `experiments/terrace/lab/journey.gd`: 장소별 목표·발견·전투·재합류, 강적과 이동 조건.
- `lab/routes.gd`, `jungle_shelves.gd`, `thresholds.gd`, `surroundings.gd`: 물가 우회, 고저 경로, 사원 회랑/마당, 원중경과 보이는 경계.
- `game/landscape.gd`, `lab/ground.gdshader`: 단일 지형 높이·충돌·포석·물 표현 계약.
- `lab/compact_hud.gd`: 전체 지형+발견물만 표시 계약 유지, 새 길/지름길 갱신.
- `game/enemy.gd`와 현행 역할 설정: 기존 적을 장소별 접근선과 지형에 맞춰 배치.
- 관련 검사: `ground_surfaces`, `terrain_probe`, `grounded_run`, `journey_routes`, `threshold_contract`, `lookout_contract`, `slope_cues`, `warning_damage`, `render_surface_motion`, `live_combat_performance`.

### 하지 않을 것

- 두 번째 문화권이나 본편 전체 맵 제작.
- 같은 직사각 마당을 늘리고 나무·바위 수만 추가하기.
- 높은 길을 무조건 안전/정답, 낮은 길을 무조건 손해로 만들기.
- 미니맵 아이콘이나 안내 문장으로 읽히지 않는 지형을 덮기.
- 얇은 별도 길 면, 임의 높이 상자, 공유 높이 계약을 우회하는 장식 지형 추가.
- 실제 전투 없이 강제처치 경로만으로 탐험·사냥 결합을 통과 처리.

### 자동검사 완료조건

- 주경로, 높은/낮은 경로, 옆길, 지름길, 입구/출구를 실제 물리 입력으로 왕복하고 저장 복원.
- 이동·카메라·적 시야·경고·공격 판정·리스폰·미니맵이 동일 높이 계약을 사용.
- 채택한 주경로·선택 샛길·출입구를 검사한다. 갈림을 도입한 맵에서는 각 경로의 실제 차이와 재연결을 별도 검증한다.
- 실제 AI를 켠 장소별 전투에서 적이 절벽 안, 막힌 길, 다른 높이의 잘못된 판정에 놓이지 않음.
- 기존 정원 오른쪽·빗물길·석문·쉼터 회귀와 새 장소 검사 지점의 `render_surface_motion` 연속 캡처 통과.
- 정상 카메라의 입구·갈림·전망·사원 접근 대표 이미지를 실제 픽셀로 비교.

### 반드시 사람이 플레이해서 확인할 항목

- 미니맵이나 안내문을 먼저 읽지 않아도 주경로·옆길·목적지가 보이는가.
- 플레이 뒤 장소를 나무나 표식이 아니라 “물가를 돌아 올라간 길”, “두 단상 사이 재합류”처럼 지형으로 설명할 수 있는가.
- 높은 길/낮은 길에서 위치 잡기, 몰이, 직접 공격 사용이 실제로 달라지는가.
- 싸움 뒤 조용한 구간과 전망이 있어 탐험 호흡이 생기는가.
- 반복 바위·수목·벽 때문에 세 장소가 같은 맵의 복제처럼 보이지 않는가.

### 다음 묶음으로 넘어가는 조건

초행 플레이어가 설명 없이 장소의 차이와 다음 이동 방향을 말할 수 있고, 선택 탐험이 있다면 그 이유를 이해하며, 지형 때문에 전투 행동이 달라져야 한다. 이동 시간이나 적 체력으로 분량만 늘어난 상태는 실패다.

## Packet 3 — 짧은 플레이에도 발견·성장이 남는 구조

### 목표

2~5분만 플레이해도 한 무리, 한 발견, 한 강화 또는 한 열린 길 중 최소 하나가 명확히 남고, 종료 후 복귀했을 때 반복 노동 없이 다음 행동을 이해하게 한다. 전체 초회 약10분 데모의 실제 시간과 만족도를 함께 잰다.

### 수정할 시스템/파일 후보

- `experiments/terrace/lab/journey.gd`: 작은 성과의 간격, 발견 역할, 장소별 체크포인트, 완료/복귀 요약.
- `lab/world.gd`, `game/save_store.gd`, `save_queue.gd`: 사건 시 저장, 종료 flush, 복원·백업·버전 이행.
- `lab/compact_hud.gd`, `lab/hud.gd`: 직전 성과·현재 장소·남은 큰 목적의 최소 정보.
- `lab/spell_growth.gd`: 강제 반복 사냥 없이 짧은 세션에서 읽히는 성장 시점.
- 필요 시 현재 정사 범위 안의 시작 동기/현장 증거/작은 결말 문구. 새 세계관을 확정하지 않음.
- 관련 검사: `journey_flow`, `journey_playthrough`, `journey_routes`, `lab_growth`, `keyboard_choices`, `save_queue_contract`, 실행본 저장 복원 검사.

### 하지 않을 것

- 런 정산, 일일 보상, 방치 보상, 임시 세션 버프, 새 화폐 추가.
- 저장하려면 거점으로 돌아가게 만들기.
- 시간을 맞추기 위한 빈 통로, 대기 타이머, 적 체력 증량.
- 일반 적 재등장, 장비 파밍, 데모→본편 저장 이전 약속.
- 자동 완주 시간을 사람 초회 10분의 증거로 사용하기.

### 자동검사 완료조건

- 새 시작→첫 성과→즉시 종료→재실행 시 처치·적 체력/생존·발견·강화·열린 길·위치가 계약대로 복원.
- 2분·5분·8분에 해당하는 서로 다른 진행 상태 스냅샷의 저장/복원 시나리오 통과. 시간은 상태 구성용이며 재미 증거로 쓰지 않음.
- 사망과 정상 종료를 구분하고, 사망 뒤 성장·발견 보존과 안전 복귀가 일치.
- 저장 실패 시 종료를 막고 재시도 가능, 기본 파일 손상 시 유효한 백업 복원.
- 키보드만으로 강화 선택, 일시정지, 저장 종료, 재실행 후 계속하기 가능.
- 최종 실행본에서 새 게임부터 완료 후 자유 탐험까지 상태 누락 없이 연결.

### 반드시 사람이 플레이해서 확인할 항목

- 2분, 5분, 8분에 멈췄을 때 각각 “이번에 얻은 것”을 말할 수 있는가.
- 재실행 즉시 직전 성과와 다음 행동을 이해하는가.
- 같은 적과 길을 불필요하게 다시 처리하지 않는가.
- 강화가 너무 늦어 짧은 세션이 공허하거나, 너무 잦아 영구 성장의 가치가 가벼워지지 않는가.
- 초행 전체 완주가 약8~12분에 들어오며 빈 이동·과한 체력·강제 대기로 시간을 채우지 않는가.
- 작은 결말이 본편의 다음 여행을 궁금하게 하지만, 긴 설명으로 플레이를 끊지 않는가.

### 다음 묶음으로 넘어가는 조건

최소 3회의 초행 플레이에서 실제 시간, 막힘, 중단 지점, 복귀 이해, 기억한 성장/발견을 기록하고 핵심 실패가 없어야 한다. 그 뒤에만 M1-D 대표 미술·음향·UI·다른 PC·Windows 패키지·Steam 공개 후보 작업으로 넘어간다.
